# Rachel Nababan - Portfolio

Modern portfolio website showcasing my work as an Informatics student specializing in Frontend Development, UI/UX Design, and Quality Assurance.

🔗 **Live Demo**: [https://rachelnababan.github.io/my_portfolio/](https://rachelnababan.github.io/my_portfolio/)

## ✨ Features

- Interactive portfolio with work experience timeline
- Project showcase with detailed modal views
- Comprehensive technical and soft skills display
- Organization and leadership activities
- Dark/light theme support
- Downloadable CV (PDF)
- Fully responsive design

## 🛠️ Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion
- React Icons

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/gabrielaamls/portfolio_rachel.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📂 Content Structure

All portfolio content is managed in `src/config/portfolioData.ts`:
- Personal information & contact
- Skills (technical & soft)
- Work experience
- Projects
- Education
- Organizations
